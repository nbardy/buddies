# Workspace home (2026-09-30)

The owner's brief, in #general on 2026-09-30: the workspace landing page
(`/buddies/workspaces/:id/channels`, `ChannelHomePane` in
`client/src/components/buddies/ChannelBrowser.tsx`) is uninspiring. It prints
the rail's channel list a second time.

**Chosen:** direction C, "Ask first". The owner said the "What should the team
build next?" headline "looks pretty sweet". This folder holds the tightened pass,
following Product Development Lead's brief
(`agent_notes/2026-09-30_workspace-landing-product-brief.md`):

| File | State |
|---|---|
| `home-desktop.png` | Populated: a short hero, a composer with a channel selector, Buddy chips, **pinned projects** (owner request, 2026-09-30), followed threads with real previews, "Waiting on you" (actual owner requests only), and a compact "Working now" row |
| `home-phone.png` | The same page on the phone's Channels tab, captured as one full-length screenshot. Projects come first, then requests, then threads; projects and threads scroll sideways |
| `home-empty.png` | A workspace with no Buddies: the composer, "Hire your first Buddy", three starter roles. The workspace is illustrative |

All three are generated by `build_home.py` from data read on 2026-09-30 through
the owner's GET endpoints (`/threads`, `/inbox` filtered to this workspace's
Buddies, `/runs?liveInWorkspace`). The grey line under each thread title is a
designer summary, because the threads endpoint does not return the latest reply
text. A text-only thread uses its opening words as its preview.

**Pinned projects.** The owner pins top-level Tasks. Each card shows the status,
the owning Buddy, the next open todo, and a progress bar segmented into done
(green), in progress (lavender) and blocked (amber). Progress is done / (all todos
- cancelled); todos in review or blocked count as unfinished. A Task with no todos
shows "No todos yet" and a dashed bar, never an invented percentage. The Task's own status stays
separate from its checklist (Product Development Lead's brief). The four cards are
example picks with their real todo counts from 2026-09-30, because nothing is
pinned yet.

Directions A (Pulse), B (Team floor) and D (Workshop) were not chosen. Their
files are in git history at 9640e23.

Rebuild and render:

```bash
cd product/design/workspace-home && python3 build_home.py
C="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$C" --headless=new --hide-scrollbars --window-size=2000,1250 --force-device-scale-factor=1.44 \
  --screenshot=$PWD/home-desktop.png file://$PWD/home-desktop.html
"$C" --headless=new --hide-scrollbars --window-size=375,812 --force-device-scale-factor=3 \
  --screenshot=$PWD/home-phone.png file://$PWD/home-phone.html
```

`assets/` holds crops from the 2026-09-30 `pnpm screenshots` capture (the rail, emblems,
Buddy faces and the phone tab bar) and real thread attachments (`prev-*`).
